# TactiQ — solution for More than a Hack 2027, Phase 1

This repository is the organisers' starter kit plus our solution. Everything that belongs to the
solution is in:

```
solution/possession_hmm.py     features from the ATD, emission scores, Viterbi decoder over H / A / D
solution/make_submission.py    one command: generate -> validate -> print SHA-256
tests/test_possession_hmm.py   self-checks on synthetic data (no match data needed)
requirements-solution.txt      pinned dependencies of the solution
jalankan.bat                   Windows one-click wrapper around the steps below
submission/TactiQ.csv          the submitted file
research/                      exploratory analysis of the tracking data; NOT used by the solution
```

The method is described in the technical document ([docs/TactiQ.md](docs/TactiQ.md)) and in the docstring at the top
of `solution/possession_hmm.py`.

## Reproduce the submission

1. Get the match bundle from the organisers and unpack it into `./data` (see `data/README.md`), or
   point `MTAH_DATA_DIR` at it. Only `data/tactical/BAR-ATH_tactical_atd.txt` and
   `data/tactical/BAR-ATH_tactical_atd.xml` are read.
2. From the repository root:

```bash
pip install -r requirements-solution.txt
python tests/test_possession_hmm.py                # optional; synthetic data only
python solution/make_submission.py --team "TactiQ"
```

This writes `submission/TactiQ.csv`, validates it with `evaluation/validate_submission.py` and
prints its SHA-256. The submitted file has

```
sha256  ee25243fdab86bdcd28b4af106140331a995c6415b3984e91db10c1c6d684498
rows    199319
```

On Windows, `jalankan.bat` runs the same three steps.

The first run reads the raw ATD (a minute or two) and caches the extracted features in
`.cache/features.npz`; later runs reuse it. The cache is derived from the match data, so it is
git-ignored and must never be committed. Use `--no-cache` to force a fresh read.

## Determinism

There is no randomness and no learned component. The decoder is pure numpy; ties are broken by
state index. The same data and the same dependency versions give a byte-identical file, which
`tests/test_possession_hmm.py` checks. The submitted file was generated with Python 3.10,
numpy 2.2.6 and pandas 2.3.3, and was regenerated byte-identically from the raw ATD with
`--no-cache` on Python 3.13.5, numpy 2.2.5 and pandas 2.2.3.

## Data

No match data is in this repository. `data/` ships empty apart from its README, and `.cache/`,
`data/processed/` and generated images are git-ignored, and the starter notebooks are committed
without outputs. The only ground-truth file present is the organisers' public five-minute window in
`evaluation/gt/`, which the solution never reads.
